# Contributing to Buildraeth

Dimraeth is in Early Access, so every game-data contribution must keep provenance visible.

## Labels
- **EA Official**: current Mudtek/Steam information.
- **Developer Confirmed**: a Mudtek developer statement or design post.
- **Demo Legacy**: historical Demo/playtest information.
- **Pending**: community observation awaiting confirmation.

For corrections, include the affected record, game version/date, a screenshot or stable source when possible, and the exact field that changed.

Do not copy large blocks of prose from third-party guides. Prefer factual values plus a source link.
